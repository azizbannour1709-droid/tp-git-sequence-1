RÉSUMÉ DES COMMANDES GIT UTILISÉES
-----------------------------------
Configuration et visualisation :
- git config --global core.editor nano : configurer l'éditeur
- git status : voir l'état des fichiers
- git log --oneline --graph --all --decorate : voir l'historique
- git tag : lister les tags

Gestion des modifications :
- git add . : indexer tous les fichiers modifiés
- git add <fichier> : indexer un fichier spécifique
- git commit -m "message" : valider les modifications avec un message
- git push : publier les commits sur le dépôt distant

Gestion des tags :
- git tag -a vX.X -m "Version X.X" : créer un tag annoté
- git push --tags : publier les tags sur le dépôt distant
- git tag : lister les tags locaux

Archives :
- git archive --format=zip : créer une archive ZIP
- git archive --format=tar.gz : créer une archive TAR.GZ
- --prefix=nom/ : ajouter un préfixe aux fichiers dans l'archive
- -o fichier : spécifier le nom du fichier de sortie
